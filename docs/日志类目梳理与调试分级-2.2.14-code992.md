# 日志类目梳理与「调试日志」分级建议

> 对象：**DLsiteFloat 2.2.14 / code 992**（`DLsiteFloat-2.2.14-code992-debug.apk`）
> 目的：盘点全量日志调用点，区分「里程碑 / 告警（常开）」与「诊断（可归入调试开关）」，
> 减少 LSPosed 日志页面（模块管理器「日志」页）的刷屏。
> 结论一句话：**已有 `debug_log` 闸门，但只覆盖了 `PlayerSourceHook` / `PlayerPositionHook` 两处；
> 真正的刷屏大户是状态栏字幕（SystemUI 进程）与核心数据层，建议按本文 C 类清单接入同一闸门。**

---

## 1. 日志通道与闸门现状

| 项 | 现状 |
| --- | --- |
| 统一出口 | `util/XposedCompat.log(...)`，logcat tag 恒为 `DLsiteSoundFloat`，priority 恒为 `INFO` |
| 是否进 LSPosed 日志包 | **是**（走 `api.log()`；仅框架注入前会退化成 `Log.println` 并打 `FALLBACK` 自曝） |
| 已存在的调试闸门 | `config/RemoteConfig.debugLog()`（配置键 `debug_log`，默认关） |
| 闸门 UI | 设置页「其他」卡片 →「调试日志」开关（`SettingsActivity#buildDebugLogRow`） |
| **闸门当前落点** | 仅 2 个文件：`PlayerSourceHook#dbg()`、`PlayerPositionHook#dumpStatusMap()` / `poll tick` |
| 不进日志包的一类 | `ConfigStore` / `SettingsActivity` 用的是 `android.util.Log` —— **只进 logcat，不刷 LSPosed 日志页**，无需处理 |

> ⚠️ `2.2.7 / code 979` 的口径（见 build.gradle 描述）是：
> 「诊断级默认关，只留里程碑（钩子挂载 / 种基线 / `>>> track changed` / 全部 WARN）」。
> 本文就是把这条口径**推广到其余 20 个文件**。

## 3. 分级判定标准

- **A 常开·里程碑**：诊断「功能有没有生效」的锚点（钩子挂载、版本、种基线、换轨上报、窗口/按钮状态跃迁）。少但关键，**保留**。
- **B 常开·告警**：以 `failed` / `WARN` / `not found` / `giving up` / `error` 结尾或含之。出问题才出现，**保留**。
- **C 调试级**：只回答「这一刻内部到底怎么算的」，正常播放就会周期性/逐句/逐帧产生。**建议接入 `debugLog()` 闸门**，默认关。

## 6. 另一个被忽视的「刷屏」大户：BUILD 版本横幅

`DlsiteSoundSubtitleModule` 在**每个被注入进程启动时**打印历史版本 changelog，
当前是 **8 条 `XposedCompat.log`**，其中 `code 988`/`987`/`983` 等单条即包含**多段拼接的
数千字长文**（`build.gradle` 顶部 1008.x 全量履历都被打进日志）。

- 影响：一次进程启动即产生数万字符日志，是「打开日志页满屏都是历史版本说明」的直接原因；
  三个进程（DLsiteSound / SystemUI / 设置页）各来一遍。
- 建议：
  1. **常开只留一行**：`==== BUILD 2.2.14 / code 992`（版本核验锚点，README 明确要求保留）；
  2. 历史 changelog 段落（`code 991` 及更早）**移入调试开关**，或整体挪到 `build.gradle`
     注释 / `docs/修复说明/` 里，不再进运行时日志。

## 7. 落地建议

1. **统一闸门**：把 `PlayerSourceHook#dbg()` 提取为一个公共工具，例如
   `util/LogGate.java`（或给 `XposedCompat` 加 `debug(String)` / `debug(tag,msg)`），
   内部读 `RemoteConfig.debugLog()`，避免每个文件各写一份。
2. **按第 5 节清单替换**：把 C 类 `XposedCompat.log(...)` 改为 `LogGate.debug(...)`；
   A/B 类保持 `XposedCompat.log(...)` 不动。
3. **保留证据锚点**（与 979 口径一致，别误伤）：
   - 常开必须留：`>>> track changed`、`soft verdict`、`Loaded N cues`、钩子挂载、状态跃迁、全部 WARN；
   - 换轨闸门的「抑制/忽略」行按 979 已是调试级，ActivityButtonHook 的
     `no player evidence` / `anchor dead` / `hide suppressed` 属于同一性质，可一并归 C。
4. **注意进程边界**：SystemUI 进程的 `StatusBarSubtitleHook` 也读同一份配置（`RemoteConfig`
   走跨进程配置通道），闸门在 SystemUI 侧同样生效。
5. **不需要动**：`ConfigStore` / `SettingsActivity` 的 `android.util.Log`（不进 LSPosed 日志包）。

### 预期收益（粗估，正常播放 1 分钟）
| 场景 | 现状 | 归调试后常开 |
| --- | --- | --- |
| 状态栏字幕开着播 10 句 | 约 40~60 行（showLine + 滚动 + 徽标） | 约 2~4 行（挂载/换轨/告警） |
| 悬浮窗 + 播放 | 约 20~40 行（scroll/几何/verdict） | 约 3~6 行 |
| 进程启动 | 数万字符（BUILD 履历全量） | 1 行版本号 |
| 播放态横跳（多实例） | 每秒可达数十条 `playback resumed/paused` | 0 |

## 8. 验证方法

1. 默认配置（`debug_log=false`）打开日志页复现一轮播放，确认只剩里程碑/告警；
2. 设置页打开「调试日志」再复现，确认第 5 节清单的行**全部回来**（诊断能力不丢）；
3. 关键取证回归：切到无字幕音轨再切回有字幕音轨，确认 `>>> track changed` /
   `soft verdict` / `[980] return to cached track` 在**默认关**下依然可见；
4. 用 `==== BUILD 2.2.14 / code 992` 那一行确认装的版本。

### 9.5 例外与偏差（务必知悉）
1. **`RemoteConfig` 内部 `log()` 刻意不过闸门**：`read()` 自身会调 `log()`，而闸门又要读 `RemoteConfig`，
   会形成 `get() → read() → log() → 闸门 → get()` 的**无限递归**；且该链路每进程只在首次读配置时走一遍，
   不构成刷屏，故保持常开（与 `logWarn` 同侧）。
2. 本文清单里**本就属于告警 / 里程碑**的行，按 §7 口径仍常开，未误伤：
   `NetworkHook` 的 `hooked ...` / `channel ready` / `>>> first response passed gates` /
   `>> parsed subtitle JSON` / `parse error` / `!! peek may be TRUNCATED` / `okio chain resolve error`；
   `ActivityButtonHook` 的 `button shown (player page)` / `capsule group hidden(...)` /
   `status bar subtitle ON/OFF` / `dismiss ignored: no subtitles`；
   `StatusBarSubtitleHook` 的 `hooked ...` / `attached to status bar` / `compat MISSING` / `config loaded`。
3. **更正**：BUILD 横幅此前误记为「三个进程各来一遍」——实际只在**宿主进程**
   （`onPackageReady → initTargetApp`）打印；SystemUI 走 `StatusBarSubtitleHook` 的单行 build 行。

### 9.6 验证
- `gradlew :app:compileDebugJavaWithJavac --offline` → **BUILD SUCCESSFUL**；
- IDE 诊断（`read_lints`）→ 0。

如需把某一行**改回常开**，只需把该处的 `LogGate.debug(...)` 换回 `XposedCompat.log(...)` 即可（一对一，无副作用）。
