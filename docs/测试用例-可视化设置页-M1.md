## 一、测试环境与数据准备

### 1.1 环境

| 项 | 要求 |
| --- | --- |
| 设备 | Ari 现役一加机型（1272×2772，App density 2.9688 / SystemUI 3.0）；PRD §8 NFR-04 |
| 系统 | Android 12+（动态取色生效）；另需一台 Android 8/9 跑回落路径（可选） |
| 框架 | LSPosed（或兼容）,已装本模块，作用域勾选 **`jp.co.eisys.dlsitesound` + `com.android.systemui`** |
| 权限 | `悬浮窗` 权限需同时授给 **DLsiteSound** 与 **模块 App**（`docs/build.md`） |
| 宿主 | DLsiteSound `jp.co.eisys.dlsitesound`；需能进入播放页并有字幕音轨 |

### 1.2 安装与环境重置（每次回归前）

```bash
# 1) 装包
adb install -r DLsiteFloat-2.2.0-debug.apk

# 2) 清掉旧的已保存配置（回到「首次安装」语义）
adb shell run-as io.github.ariinyume.dlsitesoundfloat rm -f files/dlsitefloat_config.json
adb shell run-as io.github.ariinyume.dlsitesoundfloat rm -f shared_prefs/dlsitefloat_config.xml

# 3) 改配置 / 装回旧包后必须重启 SystemUI 让新 dex 生效
#    未 root：用系统设置里的「重启系统界面」入口（或重启手机）
adb shell su -c 'killall com.android.systemui'   # 有 root 时最快
```

### 1.3 取证命令（断言用）

```bash
# ── 标准配置 JSON（PRD §FR-09 的「标准配置」本体）
adb shell run-as io.github.ariinyume.dlsitesoundfloat cat files/dlsitefloat_config.json

# ── 跨进程通道（hook 侧经 getRemotePreferences 读的就是这份）
adb shell run-as io.github.ariinyume.dlsitesoundfloat cat shared_prefs/dlsitefloat_config.xml

# ── 确认没有原子写的临时文件残留
adb shell run-as io.github.ariinyume.dlsitesoundfloat ls -l files

# ── 日志（模块 tag 固定 DLsiteSoundFloat）
adb logcat -c && adb logcat -s DLsiteSoundFloat:I

# ── 构造异常输入（debug 包可用 run-as）
adb shell run-as io.github.ariinyume.dlsitesoundfloat sh -c 'echo "{bad json" > files/dlsitefloat_config.json'
```

**日志锚点（关键字 → 含义）**

| 关键字 | 含义 |
| --- | --- |
| `==== BUILD 2.2.0 / code 956` | 装的是不是本版（每次排查先看这行） |
| `config channel ready (source=…): lang=… color=…` | 宿主（DLsiteSound）侧配置通道就绪 + 读到的参数摘要 |
| `config loaded via remote prefs: …` | 走的是 **首选** 跨进程 SharedPreferences 通道（CFG-02 的通过判据） |
| `config loaded (source=remote-prefs): …` | SystemUI 侧读到配置（CFG-03 的通过判据） |
| `remote prefs empty` / `config unavailable, using defaults` | 降级路径（RK-01 现场） |
| `style refreshed (config rev=N, source=…): active[…] inactive[…] shadow[…]` | 悬浮窗把配置换算成绘制参数的**逐项数值**（观感回归的量化依据） |
| `[host] responder installed` / `[systemui] responder installed` | 作用域探测应答器挂上了（状态卡绿色的先决条件） |
| `[host] config changed -> reloaded: …` | 保存后热重载被触发（SAV-02 的通过判据） |
| `saved (json ok, prefs ok) …` / `save failed: …` | 保存结果 |
| `status probe -> ScopeProbe.Result{systemUI=…, host=…}` | 状态卡探测结论 |
| `WARN … SystemUI build 954 != app build 956` | 跨进程版本号不一致（CFG-10） |
