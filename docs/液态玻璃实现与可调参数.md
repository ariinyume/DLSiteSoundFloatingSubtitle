# 液态玻璃悬浮窗 —— 实现原理与可调参数手册

> 对象：**v2.3.0 / code 1003**（`DLsiteFloat-2.3.0-code1003-debug.apk`）
> 源码：`view/LiquidGlassDrawable.java`（绘制内核）· `view/FloatingSubtitleView.java`（宿主与模糊下发）
> · `util/BackdropBlur.java`（合成器模糊）· `config/SubtitleConfig.java`（配置项）
> · `ui/SettingsActivity.java`（设置页「液态玻璃效果调整」卡片）

---

## 一、一句话原理

**「背景模糊」交给系统合成器做，「玻璃本身」由我们自己画。**

| 谁做 | 做什么 | 为什么这样分 |
| --- | --- | --- |
| **系统合成器**（`SurfaceControl.Transaction`） | 把**本图层背后**的真实画面糊掉 | 零权限、零采集、零额外功耗，且**天生全局**（底下是桌面也糊得到） |
| **我们自己**（`LiquidGlassDrawable`） | 在模糊层之上叠 8 层「玻璃材质」 | 只有自己能控制观感；不读背景位图 |

⚠️ 关键点：**模糊不是我们算的**。我们只是把「这个图层背后的模糊半径」设到自己的图层上
（`setBackgroundBlurRadius` + `setBlurRegions`），剩下交给 GPU/DPU。所以它跟手、不掉帧。

> 历史弯路：早期版本自己每 150ms 截一次宿主画面再跑三遍模糊 —— 有采集、有权限、有延迟，
> 且只在压在宿主页面上时才有效。code 984 换成合成器路线后全部删掉。
>
> 🔴 **code 1003 又删掉了一半：面板亮度的「自动采样」整条链路。** 以前面板还要采宿主窗口的
> 均值亮度来决定霜色，于是带来「切页抖动 / 拖动暂停 / 宿主切后台冻结 / 亮页压不到」四类问题。
> 现在这个输入**改由用户在设置页直接给出**（「环境背景亮度」滑条），采样链路（含落盘留底）
> 已整体删除。同时**光圈固定为冷白色**，不再随背景上下缘颜色染色。

## 二、绘制顺序（8 层，从下到上）

```
① 接触阴影        仅 shadowInsetPx > 0（当前为 0 ⇒ 不画）
② 圆角裁切        clipPath —— 面内所有层都不溢出玻璃
③ 面内填充 ★二选一
     A. 自适应档：薄黑底 → 自适应霜面     条件是「背后来真的糊了 + 拿到背景亮度」
     B. 静态档：  两档底色 → 均匀薄雾     兜底（模糊没生效时）
④ 顶部软受光      只占上缘 5% 高（不是整块！）
⑤ 底部薄受光      仅面板，占下缘 2.5%
⑥ 颗粒霜化        仅面板，128×128 固定种子白点噪点
⑦ 折射边光        「上缘亮 → 30% 处归零 → 70% 处仍零 → 下缘再亮」四档渐变，**固定冷白色**
⑧ 内圈细边光      仅面板，给玻璃边一点厚度层次
```

**④⑦⑧ 是「玻璃感」的来源**，不随模糊强度缩放；**③⑤⑥ 是「霜」，随模糊强度缩放**
（`blurPct = 0` 时全部归零 ⇒ 面板完全透明）。

## 三、可调参数总表

### A 组 · 面内填充（决定「更透 / 更实 / 更亮 / 更暗」）

| 常量 | 当前值 | 含义 | ⬆️ 调大 | ⬇️ 调小 |
| --- | --- | --- | --- | --- |
| `TARGET_LUM` | **0.42** | 面板最终亮度的**目标落点**（明暗度的默认映射值） | 面板整体**更亮更白**（暗背景会发白） | 更暗更"烟熏"，白字对比度变好 |
| `ADAPTIVE_VEIL_ALPHA` | **0.22** | 霜面**固定密度**（= 玻璃占多少） | 更实更暗，但**会洗色** | 更透，颜色更接近页面本身 |
| `ADAPTIVE_BASE_BLACK` | **0x14000000**（8%） | 恒定薄黑底，白字的对比度地板 | 白字更清楚，但面板更闷 | 更通透，亮页面上白字会糊 |
| `MATERIAL_FADE_FILL` | **0.20** | 霜面淡出起点 | 低模糊时霜更早消失（更透明） | 低模糊时仍保留霜 |
| `FILL_EXP` | **0.75** | 「模糊强度 → 填充量」的幂次（`fill = (blurPct/100)^0.75`） | 让低强度时填充更少（更透） | 让填充更快到位 |

### B 组 · 光效（决定「像不像一块玻璃」）

| 常量 | 当前值 | 含义 | 调节效果 |
| --- | --- | --- | --- |
| `P_GLOSS` | **0x24FFFFFF**（14%） | 顶部软受光 | 更亮 → 玻璃更"有厚度"；过大变灰 |
| `P_GLOSS_H_RATIO` | **0.05**（5% 高） | 受光覆盖高度 | ⚠️ **别调大**，v1 铺了 22% 就是「整块发灰」的元凶 |
| `P_BOTTOM_LIGHT` | **0x16FFFFFF**（9%） | 底部薄受光 | 同向参考弹窗（它的下缘确实略亮） |
| `P_RIM_TOP` / `P_RIM_BOTTOM` | **0xB0EFF4FF**(69%) / **0x6BEFF4FF**(42%) | 边缘光圈上/下缘亮度 —— **冷白色** | 这就是你说的「光圈」。太淡会「完全看不到」（真机实测过） |
| `RIM_WIDTH_DP` | **1.4** | 光圈描边宽度(dp) | 1dp 在 3x 屏只有 3px，压在运动画面上太细 |
| `RIM_FADE_TOP` / `RIM_FADE_BOTTOM` | **0.30 / 0.70** | 边光归零的两个分界 | 决定左右边缘中点有没有边光（参考机实测：**几乎没有**） |
| `P_RIM_INNER_TOP/BOTTOM` | **0x0CEFF4FF / 0x10EFF4FF** | 内圈细边光 | 给边缘"厚度层次" |
| `P_GRAIN_MAX_ALPHA` | **0x1C**（28） | 霜化颗粒强度（均值约 5%） | 磨砂颗粒感；调 0 = 完全光滑 |

> 🔴 **code 1003：光圈固定为冷白色**。底色取略偏蓝的冷白 `0xEFF4FF`，不再随背景染色 ——
> 原先那套「取背景上下缘平均色 → 提纯色相 → 与白按比例混合」（含 `EDGE_TINT`）已整体删除。

### C 组 · 几何与模糊（在 `FloatingSubtitleView.java`）

| 常量 | 当前值 | 含义 | 备注 |
| --- | --- | --- | --- |
| `LIQUID_GLASS_CORNER_RADIUS_DP` | **28** | 玻璃档圆角 | 普通档是 `CORNER_RADIUS_DP = 20` |
| `BLUR_MAX_DP` | **24f** | 模糊强度 100% 时的半径 | 实际半径 = `blurPct/100 × 24dp` |
| `GLASS_SHADOW_INSET_DP` | **0** | 阴影环宽 | **0 = 不画外阴影**（987 起为 0，回到"窗口即玻璃"） |
| `LIGHT_GLASS` | **false** | 浅色玻璃开关 | 当前走烟熏中性档 |
| `TEXT_SHADOW_RADIUS` / `_COLOR` | **7f** / **0xCC000000** | 字幕自身阴影 | 与玻璃无关，但影响可读性 |

## 四、设置页「液态玻璃效果调整」的四个滑条（**核心**）

卡片位置：设置页**「其他」卡片之前**；结构自上而下 ——
**总开关 → 环境背景亮度 → 通透度 → 明暗度 → 模糊强度 → 恢复默认**。
**总开关关闭时，下面五行全部隐藏**（`applyLiquidGlassBlurVisibility()`）。

四个滑条的**范围 / 步长 / 默认值完全一致**：`0–100`，步长 `5`，默认 **`50`**。

### 4.1 各自映射到什么

| 滑条 | 配置键 | 映射到 | 映射公式 |
| --- | --- | --- | --- |
| **环境背景亮度** | `liquid_glass_backdrop_lum` | 背景亮度 `L` | `L = pct / 100`（0 → 0.00，100 → 1.00） |
| **通透度** | `liquid_glass_transparency` | 霜面 α + 薄黑底 α | 见下表（分段线性） |
| **明暗度** | `liquid_glass_panel_lum` | 目标亮度 `TARGET_LUM` | 见下表（分段线性，分段点 = 50） |
| **模糊强度** | `liquid_glass_blur_pct` | 填充量 `fill` | `fill = (pct/100)^0.75` |

### 4.2 环境背景亮度（唯一亮度输入）

```
L = pct / 100
```

只要你告诉插件「页面大概多亮」，它就据此定霜色。**它是自适应霜面的唯一输入** ——
面板不再去读宿主窗口（code 1003 已删除自动采样）。

| pct | 0 | 40 | 50（默认） | 100 |
| --- | --- | --- | --- | --- |
| `L` | 0.00（纯黑页） | 0.40（常见页面） | **0.50** | 1.00（纯白页） |

> 历史实测：宿主页面的采样均值中位约 **0.38**、常见区间 0.35–0.45，最亮约 0.59。
> 所以默认给了 **50**（略偏亮、偏保守）—— 填得比实际亮，面板会偏灰偏闷；
> 填得比实际暗，面板在亮页上会偏亮、白字对比度下降。不知道填多少就留 50。

### 4.3 通透度（背后能透出多少）

分段线性：`pct ≤ 50` 段与 `pct > 50` 段各插值一次（**默认 50 落回历史值**）。

```
pct ≤ 50 :  霜面α = 0.55 + (pct/50) × (0.22 − 0.55)
            薄黑底α = round(0x60 + (pct/50) × (0x14 − 0x60))
pct > 50 :  霜面α = 0.22 + ((pct−50)/50) × (0.06 − 0.22)
            薄黑底α = round(0x14 + ((pct−50)/50) × (0x08 − 0x14))
```

| 通透度 | 霜面 α | 薄黑底 α | **背景透出率** |
| --- | --- | --- | --- |
| **0**（最实） | 0.55 | 0x60（38%） | ≈ **28%** |
| **25** | 0.385 | 0x3A（23%） | ≈ 48% |
| **50**（默认） | **0.22** | **0x14（8%）** | ≈ **72%** |
| **75** | 0.14 | 0x0E（5.5%） | ≈ 81% |
| **100**（最透） | 0.06 | 0x08（3%） | ≈ **91%** |

> 口径：**透出率 = (1 − 薄黑底α) × (1 − 霜面α)**。

### 4.4 明暗度（面板最终落在多亮）

分段线性，**分段点 = 默认值 50**（【code 1003】由 40 移到 50）：

```
pct ≤ 50 :  TARGET_LUM = 0.20 + pct × 0.0044          （0 → 0.20 最暗）
pct > 50 :  TARGET_LUM = 0.42 + (pct − 50) × 0.0036   （100 → 0.60 最亮）
```

| pct | 0 | 25 | **50（默认）** | 75 | 100 |
| --- | --- | --- | --- | --- | --- |
| `TARGET_LUM` | **0.20** | 0.31 | **0.42** | 0.51 | **0.60** |

⚠️ **默认 50 严格等于 0.42**（历史标定值，零回归）—— 由 `tools/verify_1000_src.py`
从源码里抽公式数字、在 Python 里独立复算来保证。

### 4.5 模糊强度（决定"糊多少 / 透多少"）

```
fill = (pct / 100) ^ 0.75          （0 → 0，100 → 1）
material = min(1, fill / 0.20)     （0.20 是淡出起点）
有效霜面 α = 霜面α × material
```

- 它是**背景模糊半径**：`实际半径 = pct/100 × BLUR_MAX_DP(24dp)`（交给合成器）；
- 它同时**缩放所有"面内填充"**（自适应霜面 / 静态底色 / 均匀薄雾 / 霜化颗粒）——
  所以 `pct = 0` ⇒ 霜全部归零 ⇒ **面板完全透明**（只剩受光与边光表达"这是玻璃"）。
- ⚠️ 顶部受光 / 底部受光 / 边光**不缩**（它们是玻璃本体，不是霜）。

## 五、参数之间的计算关系（**把四个滑条串起来**）

### 5.1 合成公式（自适应档的两步）

```
第 1 步 · 薄黑底
    X = L × (1 − 薄黑底α)

第 2 步 · 霜面补偿（反解霜色 cv）
    解   X × (1 − aFinal) + cv × aFinal = TARGET_LUM
    ⇒    cv = (TARGET_LUM − X × (1 − aFinal)) / aFinal
    其中 aFinal = 霜面α × material
    cv < 0 ⇒ 夹到 0（面板已比目标暗，霜色到底）；  cv > 1 ⇒ 夹到 1

面板实际亮度 = X × (1 − aFinal) + cv × aFinal
```

**能压到目标的前提**（可压上限）：

```
可压上限  L_max = TARGET_LUM / 透出率
```

`L > L_max` 的页面**压不下来**，面板会停在 `L × 透出率` 上（跟着页面变亮）。

### 5.2 默认档实算（`L = 0.50`、通透度 50、明暗度 50、模糊强度 50）

```
薄黑底α = 0.0784  霜面α = 0.22  fill = 0.5^0.75 = 0.5946  material = 1  aFinal = 0.22
X = 0.50 × (1 − 0.0784)               = 0.4608
cv = (0.42 − 0.4608 × 0.78) / 0.22     = 0.2755
面板 = 0.4608 × 0.78 + 0.2755 × 0.22   = 0.4200  ← 恰好落在 TARGET_LUM
透出率 = (1 − 0.0784) × 0.78           = 0.7188（≈72%）
L_max = 0.42 / 0.7188                  = 0.584
```

### 5.3 可压上限速查（`TARGET_LUM = 0.42`，即明暗度 = 50）

| 通透度 | 0 | 25 | **50（默认）** | 75 | 100 |
| --- | --- | --- | --- | --- | --- |
| 透出率 | 28% | 48% | **72%** | 81% | 91% |
| `L_max` | **1.50** | 0.88 | **0.58** | 0.52 | **0.46** |

> 读法：**纯度越高（越透），能压下来的页面越少**。
> 通透度 100 时 `L_max ≈ 0.46` —— 绝大多数页面都压不动，面板亮度 ≈ 页面本身。

### 5.4 ⚠️ 四个滑条**不正交** —— 这是理解它们的关键

- **通透度同时是"透出率"和"霜面能移动的幅度"**（霜面能移动的幅度上限就是 α）。
  ⇒ **通透度拉满时，「明暗度」几乎不起作用**（面板 ≈ 页面本身 × 0.93）。
- **明暗度调暗会让 `L_max` 变小** ⇒ 反而更容易压不到：`L_max = TARGET_LUM / 透出率`，
  分子变小、分母不变 ⇒ 上限下降。**想稳，要往"实"调（通透度↓），不是往"暗"调**。
- **「又暗又透」在物理上做不到**：暗需要「明暗度↓ + 通透度往实」，
  透需要「通透度↑」，两者冲突。想「偏暗的透明」，推荐
  **明暗度 0–15 + 通透度 20–40**。

## 七、边界与已知代价（改之前先看）

1. **很亮的页面压不到目标**：`L > L_max` 的页面会停在 `L × 透出率` 上。
   默认档 `L_max = 0.58` —— 这是 `通透度 50` 的**固有代价**，不是 bug；
   想压住就把通透度往「实」调，或把环境背景亮度填小一点。
2. **模糊靠系统**：`BackdropBlur.apply()` 走反射调 `SurfaceControl` 隐藏 API。
   任何一步失败**只返回 false**（面板退回静态档），绝不影响窗口本身。
3. **预览页与真窗不同源**：设置页预览用 `previewBackdrop` 画位图模拟背景；
   真窗靠合成器。两者**亮度可对齐，观感不会完全一样**（历史遗留，非本轮引入）。
4. **颗粒贴图固定种子** `0x20261008L` ⇒ 每次装机颗粒完全一致（便于截图对照）。
5. **合成器模糊生效时，本类不参与模糊**（半径由 `BackdropBlur` 直接设给图层）——
   否则用户拉滑条会看到两处叠加、因果说不清。
6. 🔴 **code 1003 起不再采样宿主画面** —— 以前那几条「切页抖动 / 拖动暂停 /
   宿主切后台冻结」全部随之消失；代价是**面板不再自动适配页面明暗**，
   页面明暗差很多时要自己调「环境背景亮度」。
