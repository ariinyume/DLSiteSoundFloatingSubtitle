## 二、背景与目标

### 2.1 背景

- DLsiteFloat（`io.github.ariinyume.dlsitesoundfloat`，当前 v2.1.0 / code 950）是作用于 DLsiteSound（`jp.co.eisys.dlsitesound`）与 SystemUI 的 LSPosed 悬浮字幕插件。
- **现状痛点**：字幕外观（颜色、阴影、缩放、模糊、排版等）全部硬编码在 hook 代码中（如 `StatusBarSubtitleHook` 中 `0xFFFFFFFF` 等常量），用户无法调整；每次微调都要改码、打包含验证，成本高且只有开发者能用。
- 竞品/同域参考：ColorOS-Live-Lyrics-Bridge 已验证「模块自带 Material 3 设置页 + 实时预览 + 显式 Apply and save + 配置备份恢复」的交互模型在 Xposed 字幕类插件上体验良好。

### 2.2 要解决的问题

1. 用户（含非开发者）可以不改码调整悬浮字幕外观；
2. 调整过程所见即所得，避免「改完重启才发现不好看」；
3. 配置可保存、可恢复、可迁移（换机/重装不丢）。

### 2.3 成功指标与口径

| 指标 | 口径 | 目标值 |
|---|---|---|
| 设置覆盖率 | 提供设置项的字幕外观属性数 ÷ 硬编码外观属性总数 | ≥ 90%（本期目标清单见 §10） |
| 预览一致性 | 预览区渲染结果与真实悬浮窗的参数级差异 | 零参数偏差（允许像素级抗锯齿差异） |
| 保存生效 | 点击「保存设置」后配置落盘成功率 | 100%（失败必须给明确报错） |
| 调整耗时（估算） | 从打开设置页到完成一次「改色 + 保存」的操作步数 | ≤ 5 步关键操作 |

## 三、名词与术语定义

| 术语 | 定义 |
|---|---|
| 活动行 | 当前正在演唱/显示的字幕行（高亮、放大、最亮的那一行） |
| 非活动行 | 已唱过或未唱到的字幕行（默认弱化显示） |
| 预览草稿态 | 用户改动尚末「保存设置」的状态；只影响预览区，不影响真实悬浮窗 |
| 已保存态 | 点击「保存设置」后，配置已写入标准配置文件的状态 |
| 标准配置 | 插件约定的字幕配置文件（键表见 §10），设置页与 SystemUI hook 共同的唯一事实源 |
| SystemUI 重启 | 杀死并重建 `com.android.systemui` 进程，使 hook 侧重新初始化 |
| MD3 | Material Design 3 设计语言（动态取色、色槽、圆角卡片、 segmented button、slider、switch 等） |
| primaryContainer / errorContainer | MD3 颜色色槽名，分别用于「成功/激活」与「错误/未激活」语义底色 |
| 色槽 | MD3 中预定义的颜色角色（如 onPrimaryContainer、outline 等） |

## 四、需求范围

### 4.1 包含（本期）

1. 设置页整体信息架构与 MD3 视觉规范（两屏长页 + 吸底操作栏 + 吸顶预览）；
2. 模块激活状态卡（含 SystemUI 授权状态分立展示、语言切换按钮）；
3. 字幕调整实时效果预览区（壁纸 + 悬浮窗示意 + 示例字幕，拖动实时重绘、吸顶跟随）；
4. 主字幕（活动行）调整组：颜色、阴影颜色、阴影强度、阴影半径、主字幕高亮、主字幕放大倍数、恢复默认；
5. 非活动行字幕调整组：模糊开关与半径、缩放开关与比例、恢复默认；
6. 字幕排版组：字重、对齐、字幕间行距、长字幕内换行额外行距、恢复默认；
7. 其他组：状态栏字幕开关、字幕配置备份与恢复（导出/恢复）、字幕显示时保持屏幕常亮；
8. 吸底操作栏：重启系统界面（带二次确认）、保存设置（写入标准配置并使悬浮窗刷新）；
9. 设置页三语 i18n：简体中文 / 繁體中文 / English；
10. 配置文件 Schema（键名、类型、范围、默认值、版本号）与设置页 → SystemUI 的配置传递方案。

### 4.2 不包含（本期不做）

| 项 | 说明 | 去向 |
|---|---|---|
| 字幕预设主题（Default/Soft/Vivid/Minimal 式） | 参考项目有，但本期先把参数面板做扎实 | 后续版本 |
| 逐词高亮 / 歌词时间轴编辑 | DLsiteSound 字幕源为整句 cue，无逐词数据 | 不做（场景不符） |
| 在 DLsiteSound App 内的插件界面多语言 | 语言切换只作用于设置页本身（见 FR-02） | 明确不做 |
| 设置页深色主题的独立定制 | 跟随系统 MD3 动态深浅色，不做手动模式选择 | 跟随系统 |
| 配置云同步 | 本期仅本机导出/导入 | 后续版本 |

## 五、方案对比与选型说明

### 5.1 候选方案

| 维度 | 方案 A：独立设置 Activity + MD3 原生控件 + 配置文件中转（推荐） | 方案 B：设置页做成悬浮窗内嵌面板 | 方案 C：沿用 LSPosed「无 UI + 改配置文件手编」 |
|---|---|---|---|
| 实现成本 | 中（新增 MainActivity + 预览控件 + 配置读写层） | 高（SystemUI 进程内做交互面板，事件冲突多） | 低 |
| 开发复杂度 | 中 | 高 | 低 |
| 用户体验 | 好：预览所见即所得、吸顶预览 + 吸底操作 | 中：面板遮挡 DLsiteSound 本体 | 差：手编 JSON，非开发者不可用 |
| 风险 | 低：常规 Android 组件 | 高：SystemUI 内触摸/焦点冲突 | 中：手编易写错范围值导致渲染异常 |
| 上线时间 | 快（可按 §13 分期） | 慢 | 立即（但等于不解决需求） |
| 综合评价 | **推荐** | 备选 | 拒绝 |

### 5.2 推荐理由

- 与参考项目同构（独立设置 App + 预览 + 显式保存），交互心智已被验证；
- 设置页跑在插件自身进程，不与 SystemUI 抢交互；配置经「标准配置文件」单向流向 SystemUI，边界干净；
- 便于按 MVP 分期交付（§13）。

### 5.3 配置传递选型（实现关键决策）

| 方案 | 说明 | 评估 |
|---|---|---|
| A1（推荐） | 设置页写 SharedPreferences 并将配置文件置为世界可读（world-readable），SystemUI 侧 hook 用 `XSharedPreferences` 读取；保存后 SystemUI 侧 FileObserver 监听变更，热重载样式 | Xposed 生态成熟做法；热重载可让「保存即生效」，减少重启 SystemUI 次数 |
| A2（兜底） | 配置落盘后不热重载，保存成功提示「点击重启系统界面生效」 | 实现最简单，但每次调整都要重启，体验差；作为 A1 失败时的降级 |

**演进路径**：本期按 A1 实现，A2 作为兼容降级开关（配置键 `hot_reload`，默认开）；后续版本再考虑预设主题与云备份。

## 六、用户角色与使用场景

### 6.1 用户画像（基于 Ari 的使用背景，画像为待确认假设）

- **角色**：DLsiteSound 重度用户 / 拼团吃谷玩家，同时是本插件作者与测试者（发布到 LSPosed 后有非开发者用户）。
- **能力水平**：熟练（自己会打包含验证），但目标用户包含只会装 APK 的普通玩家。
- **典型痛点**：字幕在某部作品背景上看不清、想要更小/更大的字号、想让非活动行更淡、换机后不想重调。

### 6.2 核心场景

| 场景 | 主流程 |
|---|---|
| S1 换个字幕颜色 | 打开设置页 → 点色板/自定义取色 → 预览实时变色 → 保存设置 |
| S2 弱化非活动行 | 开「模糊非活动行」→ 拖模糊半径 → 预览观察 → 保存 |
| S3 排版微调 | 调字重/行距 → 长字幕预览验证换行 → 保存 |
| S4 换机迁移 | 旧机导出配置 → 新机恢复 → 重启系统界面 |
| S5 排障 | 状态卡显示未授权 → 按引导去 LSPosed 勾选作用域 → 重启系统界面 → 状态卡变绿 |

> │ ⑤ 字幕排版                                      │
> │ ⑥ 其他                                          │

### FR-01 模块激活状态卡

**描述**：设置页顶部状态卡，三态呈现，右侧固定语言切换按钮。

**业务规则**：
1. 已激活态用 MD3 `primaryContainer` 底色 + 勾形图标；未激活态用 `errorContainer` 底色 + 叉形图标（标注 1）。
2. 卡片内容两行：标题（模块已激活 / 模块未激活）+ 副标题 `v{版本名} (code {版本号}) · {SystemUI 授权状态}`。
3. **模块激活判定**：检测 DLsiteSound（`jp.co.eisys.dlsitesound`）是否已在 LSPosed 中授权本模块；已授权即显示「模块已激活」。
4. **SystemUI 授权分立检测**：`com.android.systemui` 的授权状态单独检测，已授权显示「SystemUI 已授权」，未授权显示「SystemUI 未授权」。
5. 数据源：插件自身（版本信息取自本 APK；授权状态经 hook 心跳标记文件间接判定——SystemUI 侧 hook 启动成功后写入带版本号的心跳文件，设置页读该文件判定；方案与降级见 §14 风险 RK-02）。
6. 语言切换按钮：胶囊按钮（🌐 图标 + 当前语言名），点击弹出三选一：简体中文 / 繁體中文 / English。

**验收标准**：
- Given 模块未激活，When 用户打开设置页，Then 状态卡为 `errorContainer` 红底、显示「模块未激活 · v2.1.0 (code 950) · SystemUI 未授权」。
- Given SystemUI 已授权但 DLsiteSound 未授权，Then 显示「模块未激活」且副标题中 SystemUI 状态为「已授权」（两状态独立）。
- Given 用户点击语言按钮并选择 English，When 页面刷新，Then 设置页全部文案切为 English，且再次打开记忆上次选择。

### FR-02 设置页语言切换（i18n）

**描述**：设置页支持简体中文 / 繁體中文 / English 三语（标注 1）。

**业务规则**：
1. 只切换**设置页 UI** 的显示语言；
2. 不改变插件在 DLsiteSound 软件内的悬浮字幕显示语言，也不改变 DLsiteSound 本身的语言；
3. 选择持久化到标准配置（`ui_language`，值为 `system` 时跟随系统）。

**验收标准**：
- Given 语言为 English，When 用户在 DLsiteSound 播放字幕，Then 悬浮窗内容不受设置页语言影响。
- Given 选择「跟随系统」，When 系统语言为繁體中文，Then 设置页显示繁體中文。

### FR-03 字幕调整实时效果预览区（吸顶）

**描述**：页面顶部固定一块实时预览区（标注 2、7），是所有参数调整的所见即所得画布。

**业务规则**：
1. 预览区三层合成：**用户手机当前壁纸** + **悬浮窗示意（毛玻璃圆角卡片，按真实悬浮窗几何比例渲染）** + **示例字幕**。
2. 示例字幕固定使用以下 5 行（含 1 个活动行，用于同时观察活动行/非活动行效果）：
   - 因为想被饲养，也因为想饲养别人（非活动行）
   - 我们互相带上项圈吧（非活动行）
   - **除了我之外**（活动行：加粗、高亮、放大）
   - 绝对不会出现有比我能给你幸福的人（非活动行）
   - 哪里也不要去（非活动行）
3. **实时性**：任何控件拖动/切换过程中预览即时重绘（每帧重绘，不落盘）；
4. **保存动作**：点击「保存设置」后才把当前预览参数写入标准配置，并触发插件悬浮窗本体刷新；
5. **吸顶（标注 7）**：当页面向下滚动、预览区到达顶部时，预览区保持固定在顶部可见；其余设置区从其下方穿过后继续滚动（sticky header 行为）；
6. 预览区使用与编辑无关的独立渲染层（自定义 View），不依赖真实 hook。

**验收标准**：
- Given 用户拖动「阴影半径」滑块，When 停在 15%，Then 预览区字幕阴影立即呈现对应模糊半径，无需保存。
- Given 页面滚动到「字幕排版」区，When 预览区顶边到达屏幕顶栏下沿，Then 预览区固定吸顶、下方内容继续滚动穿过。
- Given 用户调整后未保存直接退出设置页，When 重新进入，Then 预览恢复为**已保存**配置，草稿丢弃（不静默保存，见 §12 异常 E-05）。

### FR-04 主字幕（活动行）调整

**描述**：活动行外观参数组（分区标题「主字幕（活动行）调整」）。

**控件与范围**（标注 3、4）：

| 控件 | 类型 | 范围/选项 | 步长 | 默认值（估算，待 Ari 确认） |
|---|---|---|---|---|
| 主字幕颜色 | 色板（白/黑/绿/红/橙/灰 6 预设）+ 自定义按钮 🎨 | 任意 ARGB | — | 白 #FFFFFF |
| 阴影颜色 | 色板（黑/蓝/橙/紫/棕/青 6 预设）+ 自定义按钮 🎨 | 任意 ARGB | — | 黑 #000000 |
| 阴影强度 | 滑块 | 0–100 % | 1 % | 0 % |
| 阴影半径 | 滑块 | 5–20 % | 1 % | 15 % |
| 主字幕高亮 | 滑块 | 50–100 % | 1 % | 50 % |
| 主字幕放大倍数 | 滑块 | ×0.8–1.5 | 0.1 | ×1.0（草图滑杆旁标 ×1.5，两值矛盾，见 §14 DK-03） |
| 恢复主字幕默认设置 | 文字 + ↺ 重置胶囊按钮 | — | — | 点击恢复上表默认值 |

**自定义取色弹层（标注 3）**：点击「🎨」弹出取色面板，包含：色轮（hue）、明度/饱和度方形取色区、HEX 输入框（支持 `#RRGGBB` / `#AARRGGBB`）、[取消] [应用] 按钮；「应用」回写对应色板选中态并更新预览。

**验收标准（节选）**：
- Given 阴影强度 = 0，When 查看预览，Then 活动行无可见阴影。
- Given 用户在 HEX 框输入非法值 `#GGHHII`，When 点击应用，Then 输入框标红提示格式错误，不关闭弹层。
- Given 点击「恢复主字幕默认设置」，When 确认后，Then 本组 6 项参数回到默认值、预览同步刷新，**其他组参数不变**。

### FR-05 非活动行字幕调整

**描述**：非活动行弱化策略（分区标题「非活动行字幕调整」，标注 5）。

| 控件 | 类型 | 范围 | 默认值（估算，待确认） | 联动规则 |
|---|---|---|---|---|
| 模糊非活动行 | Switch | 开/关 | 开 | 关闭时「模糊半径」滑块**隐藏** |
| 模糊半径 | 滑块 | 0–16 × 0.5 px（即 0–8 px，显示格式 `8 × 0.5px`） | 8 × 0.5px | 仅模糊开启时可见 |
| 缩放非活动行 | Switch | 开/关 | 开 | 关闭时「缩放比例」滑块**隐藏** |
| 缩放比例 | 滑块 | 50–100 % | 50 % | 仅缩放开启时可见 |
| 恢复非活动行字幕默认设置 | ↺ 重置胶囊按钮 | — | — | 恢复上表默认值（含开关状态） |

**验收标准**：
- Given 「模糊非活动行」关闭，When 查看本组，Then 「模糊半径」行不渲染（占位收回，非置灰），预览中非活动行无模糊。
- Given 模糊半径拖到 16，When 查看，Then 值显示 `16 × 0.5px`（=8px）且滑块到达右端点。

### FR-06 字幕排版

**描述**：文本排版参数组（分区标题「字幕排版」，标注 8）。

### FR-08 吸底操作栏（重启系统界面 / 保存设置）

**描述**：页面底部固定的双按钮操作栏（标注 6）。

**业务规则**：
1. 操作栏**始终固定在页面底层可见**（不随内容滚动，标注 6「保持保持在页面上层」）；
2. [重启系统界面]：次要按钮（surface 变体灰底）；点击弹二次确认对话框（「将重启 SystemUI，状态栏与通知会短暂消失，确定？」）→ 确认后执行 SystemUI 软重启；用于授权变更、hook 异常等场景；
3. [保存设置]：主要按钮（primary 实心）；点击将全部草稿参数写入标准配置文件（含 `schema_version` 与保存时间戳），成功后：Toast「已保存」+ 触发悬浮窗本体刷新（热重载）或提示需重启（降级，见 §5.3）；
4. 保存采用**全量保存**（不分组保存）；保存后草稿态清零；
5. 存在未保存改动时，返回键/滑动手势退出需弹确认「有未保存的更改」。

**验收标准**：
- Given 未做任何修改，When 查看「保存设置」，Then 按钮仍可点击但保存后提示「配置无变化」。
- Given 点击「重启系统界面」并确认，When SystemUI 重建完成，Then hook 重新加载并按已保存配置渲染字幕。
- Given 有未保存改动按返回，When 弹窗中选择「不保存」，Then 草稿丢弃、配置保持上次保存值。

### FR-09 配置文件 Schema 与读写（技术需求）

1. 配置文件：JSON，含 `schema_version`（整数，本版 = 1）、`saved_at`（ISO 8601）、全量参数键（§10）；
2. 写入采用「临时文件 + 原子替换」防写坏；
3. SystemUI 侧读取失败时**整体回退默认值**并在日志标记，禁止半套参数生效；
4. 键名冻结：新增键只增不改名；废弃键保留解析兼容（读旧配置不丢字段）。

## 九、业务流程与状态流转

### 9.1 编辑-保存状态机（核心）

```
[已保存态] --用户改动任一参数--> [草稿态] --保存设置(成功)--> [已保存态]
    ^                              |
    |                              |--未保存退出(确认放弃)--> [已保存态](回滚预览)
    |                              |--保存设置(失败)--------> [草稿态]（报错，参数保留）
    └------ 恢复默认(仅改草稿) ------ [草稿态]
```

规则：
- 状态 A（草稿）下所有改动**只改预览**；状态 B（保存）才写配置文件；
- 每组「恢复默认」只重置本组，且属于草稿改动（仍需保存）；
- 保存失败（磁盘满/权限异常）必须保留草稿并给出可读错误。

### 9.2 保存生效流程

```
点击保存设置 → 校验范围值(越界夹紧) → 序列化 JSON → 原子写配置文件
  → 成功：通知 SystemUI（FileObserver 触发热重载）→ 悬浮窗刷新
  → 热重载失败/未实现：提示「请点击重启系统界面生效」（A2 降级）
```

### 9.3 恢复配置流程

```
点击恢复 → SAF 选文件 → 解析 + schema 校验（版本/键完整性/范围合法性）
  → 通过：二次确认「将覆盖当前配置」→ 写入 + 预览刷新 + 提示是否重启 SystemUI
  → 失败：明确报错（版本过新 / 文件损坏 / 键缺失），当前配置不变
```

### 15.2 原型思路补充

- **布局**：单 Activity + NestedScrollView；预览区为 sticky header（CoordinatorLayout + AppBarLayout scrolling behavior 或自定义 sticky 逻辑）；操作栏 `wrap_content` 固定于底部。

- **取色弹层**：BottomSheetDialog；色轮可用现成开源组件（合规引用注明许可）。
- **状态卡**：MaterialCardView + `setCardBackgroundColor` 按 Material 色槽取值，禁止硬编码十六进制色值。
