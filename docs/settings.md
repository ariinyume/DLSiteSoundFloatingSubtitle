# DLsiteFloat 设置项说明

> 面向**使用者**的一页说明。设置项文案与默认值全部取自源码，不是设计意图：
> 键名与范围 ← `config/SubtitleConfig.java` · 界面标签 ← `ui/Strings.java`（三语 enum）· 控件行为 ← `ui/SettingsActivity.java`
> 对应版本：**v2.2.14（code 995）**
> 仓库：`ariinyume/DLSiteSoundFloatingSubtitle`

---

## 0. 三分钟上手

1. 在 **LSPosed** 里给两个作用域打勾：✅ `DLsiteSound`（字幕数据与悬浮窗）、✅ `SystemUI`（状态栏字幕）
2. 勾选后**重启系统界面**（或重启手机）
3. 打开 DLsiteSound → 进入任意作品 → 从模块入口进 **可视化设置**
4. 顶部状态卡必须显示 **模块已激活**。若显示 **DLsiteSound 未运行**，按提示先启动一次应用即可

> ⚠️ 状态卡不是装饰。它是「设置能不能生效」的唯一判据：
> **模块未激活** ⇒ 整页控件禁用、保存按钮不可用。

## 1. 状态卡（只读，不能改）

| 显示 | 含义 | 你该做什么 |
| --- | --- | --- |
| 🟢 **模块已激活** | 一切正常，设置可用 | — |
| 🟡 **模块未激活** | 没勾作用域，或没重启 | 去LSPosed 勾选后重启系统界面 |
| ⚪ **模块状态未知** | 探测中或未收到响应 | 等几秒；仍不变就看下方提示 |
| 🔵 **SystemUI 已授权 / 未授权 / 未知** | SystemUI 侧作用域状态 | 未授权 ⇒ 状态栏字幕功能不可用 |
| ⚠️ **DLsiteSound 未运行** | **不是未授权** | **启动一次 DLsiteSound 应用**（进任意作品即可），已保存的设置会在它启动后自动生效 |

**三个常见误解**：

- 「未运行」≠「没授权」。宿主不是常驻进程，开机后没启动过，里面就没有本模块代码，自然 ping 不到。
- 设置改了但没反应，**先看状态卡**。九成是这里没绿。
- 「重启系统界面」按钮就在设置页底部，比手动重启手机快。

## 3. 悬浮窗面板外观

### 3.1 液态玻璃

| 项 | 说明 | 默认 |
| --- | --- | --- |
| **液态玻璃** | 悬浮窗面板与播放页字幕按钮改为玻璃质感 | 关 |
| └ **模糊强度** | 50~100%，步进 5 | **60%** |
| └ **面板明暗** ⭐ | 0~100%，步进 5 — 面板整体落多亮 | **40%** |
| └ **通透度** ⭐ | 0~100%，步进 5 — 背景能透出多少 | **50%** |
| └ **背景亮度自动采样** ⭐ | 开关 — 关掉后**不再采样背景**，改用下面那条固定值 | **开** |
| └ **背景亮度** ⭐ | 0~100%，步进 5 — 仅「自动采样」关闭时出现 | **40%** |

⭐ 后两项是 **code 1000 起**新增的（只在液态玻璃开启时出现）。

⚠️ **三个必须知道的点**：

1. **开启液态玻璃后，「悬浮窗颜色」不可调整**（玻璃会盖住纯色底）。
2. **模糊强度是「有背景就模糊背景，没背景就模糊玻璃自己」**：
   - 取到背后画面（宿主提供背景位图）⇒ 作用于**画面本身**
   - 取不到 ⇒ 退化为作用于**玻璃自身**
   数值越高越糊。如果开启后觉得糊得看不清，先调回 50~60。

3. 🔴 **「面板明暗」和「通透度」不是两个互相独立的旋钮** ——
   通透度越高，背景越占主导，「面板明暗」能起的作用就越小：

| 通透度 | 背景透出 | 「面板明暗」能移动面板亮度的幅度 |
| --- | --- | --- |
| 0（最实）| ≈ 28% | 大（面板亮度 0.20 ~ 0.56）|
| 50（默认）| ≈ 72% | 中 |
| **100（最透）** | ≈ 91% | **几乎为零**（面板亮度 ≈ 页面本身）|

   ⇒ **通透度拉满时拖「面板明暗」几乎看不出变化**，这不是坏了，是物理
   （背景透出来 91%，面板当然只能等于背景）。

   **想要「偏暗的透明」**：**面板明暗 0~15 + 通透度 20~40**。
   ⚠️ 关键是**别把通透度拉满**。

   「面板明暗」的映射（code 1001 起分段，默认 40 严格 = 0.42 不变）：

```
0 → 0.20（最暗）· 40 → 0.42（默认）· 100 → 0.60（最亮）
```

### 3.2 悬浮窗颜色

| 项 | 取值 | 默认 |
| --- | --- | --- |
| 悬浮窗颜色 | 预设色板 + 自定义十六进制 | **深蓝黑** `#FF0E1420` |

预设色板：白 / 黑 / 绿 / 红 / 橙 / 蓝 / 紫 / 青 / 深蓝黑 / 自定义。
自定义填 `#RRGGBB` 或 `#AARRGGBB`（例：`#FF8A65`）。

⚠️ 开了液态玻璃后本项自动失效。

## 4. 主字幕 / 活动行（GROUP_MAIN）

> 「活动行」= 当前正在唱/正在说的那一行。

| 项 | 范围 | 默认 | 调大 / 调小的效果 |
| --- | --- | --- | --- |
| **主字幕颜色** | 色板 / 自定义 | **白色** `#FFFFFFFF` | — |
| **阴影颜色** | 色板 / 自定义 | **黑色** `#FF000000` | — |
| **阴影强度** | 0~100% | **50%** | 调大 = 影子更实；调到 0 = 完全无阴影 |
| **阴影半径** | 5~20 px | **10 px** | 调大 = 影子更弥散；小字上建议 ≥10 |
| **活动行不透明度** | 50~100% | **100%** | 调小 = 当前行变淡（会和不活动行混淆，慎用） |
| **主字幕放大倍数** | ×0.8 ~ ×1.5，步进 0.1 | **×1.0** | 字太大在窄屏会挤掉整行 |

🔹「恢复主字幕默认设置」按钮可单独复位这一组。

---

## 5. 非活动行字幕（GROUP_INACTIVE）

> 「非活动行」= 上下相邻的、还没唱到的行。做得好看，上一句下一句就自然。

| 项 | 范围 | 默认 |
| --- | --- | --- |
| **模糊非活动行** | 开 / 关 | **开** |
| └ **模糊半径** | 0~16 步进 | **6** |
| **缩放非活动行** | 开 / 关 | **开** |
| └ **缩放比例** | 50~100% | **90%** |

🔹 两组是**独立开关**。常见组合：

- **想聚焦当前句** → 模糊开+ 缩放开（默认这套）
- **想通读上下文** → 模糊关 + 缩放开
- **嫌屏幕太花** →模糊开 + 缩放关 + 比例调到 80% 以下

⚠️ 模糊半径超过 **12** 在小字号下会糊成一片，建议 ≤10。

🔹「恢复非活动行字幕默认设置」按钮可单独复位这一组。

## 6. 字幕排版（GROUP_TYPO）

| 项 | 范围 | 默认 |
| --- | --- | --- |
| **对齐** | 左对齐 / 居中 / 右对齐 | **居中** |
| **字幕间行距** | −5.0 ~ +5.0 dp | **0 dp** |
| **长字幕内换行额外行距** | 0 ~ 5.0 dp | **0 dp** |

🔹 两个行距的区别：

- **字幕间行距** = 行与行之间的疏密（长句之间）
- **换行额外行距** = 一句太长被折行时，**那一句内部**多出来的间距

💡 折行后觉得挤 → 调「换行额外行距」到 1~2。
💡 行与行挤在一起 → 调「字幕间行距」到 1~2。

⚠️ 行距是**唯一允许负值**的项（−5 ~ +5），用于压紧整体高度。

🔹「恢复字幕排版默认设置」按钮可单独复位这一组（含悬浮窗颜色）。

## 7. 其他（GROUP_MISC）

| 项 | 说明 | 默认 |
| --- | --- | --- |
| **状态栏字幕功能** | 在系统状态栏显示当前字幕 | 关 |
| └ 提示 | ⚠️ **此开关无法直接撤销 SystemUI 权限**，要去 Xposed 插件管理器里撤 | — |
| **调试日志** | 排查问题才开| 关 |

⚠️ **状态栏字幕的两个硬约束**：

1. **它需要 SystemUI 作用域**。没授权的话开关会失效。
2. **开了之后想彻底关掉，改这个开关不够** ——
   状态栏字幕是往 SystemUI 里注入的，**关闭开关只是不再显示，已经注入的权限要去
   Xposed 插件管理器里手动撤销**。这是系统限制，不是 bug。

⚠️ **调试日志日常保持关闭**。打开会显著增加日志量（真机实测约 100 行/分钟），
只在「反馈问题需要排查」时临时开。

## 8. 备份与恢复

| 按钮 | 作用 |
| --- | --- |
| **导出** | 把当前全部字幕配置存成一个 `.json` 文件 |
| **导入** | 从之前导出的 `.json` 恢复 |

🔹 **建议在调完一组设置后导一次**。尤其是液态玻璃和排版这类「调半天不知道改了啥」的项。

⚠️ 导入可能的失败提示：

| 提示 | 原因 |
| --- | --- |
| 非字幕配置文件 | 选错文件了 |
| 字幕配置文件为空 | 文件是空的 / 损坏 |
| 文件内容损坏 | 同上|
| **配置文件版本过新** | 导出的版本比你当前模块新⇒ **先升级模块再导入** |

💡 换机 / 重装模块前，**一定先导出**。

## 9. 保存机制

| 提示 | 含义 |
| --- | --- |
| **已保存** | 写入成功 |
| **配置无变化** | 你没改任何东西，不用写 |
| **保存失败：…** | ⚠️ 罕见，见下方排查 |

⚠️ **离开页面前会问「有未保存的更改」** —— 可以选「不保存」丢弃。

### 排查清单

| 症状 | 先查 |
| --- | --- |
| 改了没反应 | ① 顶部状态卡是否🟢 ② 是不是忘了点**保存** |
| 悬浮窗没出现 | ① 是否进了**播放页**（非播放页不显示）② 状态卡是否 🟢 |
| 状态栏字幕不显示 | ① **SystemUI 是否已授权** ② 是否开了**状态栏字幕功能** |
| 状态栏关了还在显示 | 需去 **Xposed 插件管理器**撤 SystemUI 权限（见 §7） |
| 液态玻璃很糊 | 模糊强度调回 **50~60**；或关掉液态玻璃 |
| 日志刷屏 | 关掉**调试日志** |
